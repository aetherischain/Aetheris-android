# AetherisWallet Changelog

All notable changes to **AetherisWallet** will be documented in this file.

---

## [1.0.1-BETA4] - 2026-07-24
### Added
- **Staking Support:** Added Stake fragment UI for Aetheris PoS staking.
- **Side Menu:** Moved Terminal to the main navigation menu.
- **Notifications with Audio:** Integrated sound notifications for wallet events.
- **Support & Buy Links:** Updated Buy AETH URL and Customer Support contact links.
- **Localization:** Expanded multi-language support (added Polish translations and updated language selector).
- **Branding & Assets:** Updated high-resolution Aetheris logotypes, launcher icons, and branding.

---
